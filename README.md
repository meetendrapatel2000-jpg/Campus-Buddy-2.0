# Campus-Buddy-2.0 🎓

**Campus-Buddy-2.0** is a Python and Tkinter-based Student Management System designed to easily manage student records, calculate grades, and generate reports.

---

## 🌟 Key Features

* **Modular Navigation:** Simple and clean user interface for smooth navigation.
* **CSV Data Persistence:** All student data is safely saved in CSV files.
* **Automated Grade Calculation:** Calculates grades automatically based on student marks.
* **Report Generation:** Generates detailed student progress reports effortlessly.
* **Data Backup Support:** Built-in feature to back up and protect your data.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.x
* **GUI Library:** Tkinter (Included with standard Python installation)
* **Storage:** CSV File System
